## 全局约束

- 中文、Python 3.11、NumPy 为唯一必需第三方库。代码、题面、测试均离线可用；不依赖 GPU、Redis 或外部数据集。
- 初学者先学习普通 Python，再学习 NumPy；所有考查算法自行实现，不直接调用机器学习框架。
- 范围：公共 AI 基础及 AI 系统优化算法，包括基础 CNN、GAN、转置卷积；分布式训练为单机数值模拟。
- 总计 P001–P080 和 M01A、M01B、M02A、M02B、M03A、M03B、M04A、M04B；不将原创训练题称为真题或高频题。
- 每题完整题面、约束、输入输出格式、手算样例、三级提示、练习文件、单独的可独立运行的参考解、题解、至少 5 个测试。
- 练习不能导入答案；答案不能依赖其他答案。每份答案可作为单文件提交。重复的入门输入输出代码是有意的教学设计，避免公共框架隐藏算法。
- 参考答案代码为独立编写，引用只用于核对定义与实现思路；逐题标注一手来源链接。
- 算法例题尽可能小且可手算。算法随机性默认改成显式输入的初值/插值系数，确需随机时固定并解释种子。
- 测试应先于对应实现编写并观察失败；预期值来自手算、独立枚举或独立数学性质，不能只运行参考答案生成预期值。

## 统一接口

普通题目录 `chapters/01_python/problems/P001/`（其余章节见任务简报）；每题目录有 `README.md`、`exercise.py`、`cases.json`。
参考代码 `solutions/P001.py`，讲解 `solutions/P001.md`。模拟题放 `exams/mock01/M01A/`，答案同样放 solutions。

`cases.json` 是 UTF-8 JSON 对象：

```json
{
  "id": "P001",
  "chapter": "01",
  "title": "第一行输出",
  "mode": "text",
  "requires": [],
  "cases": [
    {"name": "基本样例", "input": "", "expected": "Hello, Python!\n"}
  ]
}
```

- `mode` 仅 `text`、`int`、`float`；`requires` 为 `[]` 或 `["numpy"]`；案例必须至少 5 个，`name` 唯一。可选 `timeout` 单位秒，默认 5 秒。
- 比较 text 时允许 CRLF/LF 差异、行尾空白、末尾空行差异，但保留行内内容；int/float 先验证行数、每行元素数，再逐项比较。整数严格以十进制整数解析；浮点 abs_tol=rel_tol=1e-6，非有限数拒绝。
- 每题全部标准输入输出，无提示性 stdout。初期 exercise 提供详细脚手架；未完成处 `raise NotImplementedError("请按题目提示完成这里")`。第一章避免提前使用函数、推导式等尚未讲授语法。
- README 包含完整样例输入/输出（与 cases 第一个案例一致）、手算步骤、分级提示（可折叠）、运行与检查命令、下一题或章节入口。
- solution.md 包含思路、代码关键步骤、复杂度、易错点、来源；复杂度明确对应实际实现。参考代码有中文解释性注释。
- `python check.py P001`、`python check.py --chapter 01`、`python check.py --all --solution`；`--list` 列出索引，`--solution` 仅维护/对照时使用；可选 `--timeout` 覆盖超时方便验收。
- 发现题目仅使用上述两个目录模式。`check.py` 不要求中心注册表，新增题目即能发现。默认检查练习、默认不展示答案。
- 所有学习命令给出根目录操作和无需激活的 `.\.venv\Scripts\python.exe` 形式。
