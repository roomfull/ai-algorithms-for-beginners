# P018 点积

本题为原创训练题。先修：先完成 P017；本题新概念见下方‘开始前先读’。

## 任务

计算两个同维向量的点积：每个位置相乘，再将所有乘积相加。理解线性模型中‘特征乘权重再汇总’的基本操作。

## 开始前先读

点积符号 a·b 代表 Σaᵢbᵢ。NumPy 对同形状数组的 `a * b` 是逐元素乘法，结果仍是一排数；再 `.sum()` 才得到单个点积。点积不等于两个向量各自先求和再相乘，也不等于距离。它可能为正、负或零。

## 输入输出与约束

输入两行等长实数序列。输出一行点积，允许为负数。

维数1–1000，元素绝对值≤10000，两行长度相同。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `float`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
1 2 3
4 5 6
```

输出：

```text
32
```

手算：a=(1,2,3)，b=(4,5,6)，逐项乘积4、10、18，相加32。a=(-2,3)，b=(4,-1)时结果为-8-3=-11。两个非零向量(1,0)、(0,1)点积为0。

## 三级提示

<details><summary>提示1</summary>

每个位置只和另一向量相同位置相乘。

</details>

<details><summary>提示2</summary>

先得到 a*b 的乘积数组，不要对它开平方。

</details>

<details><summary>提示3</summary>

输出 (a*b).sum()；可以用手算32验证没有误写为 (a.sum()*b.sum())。

</details>
