# P021 索引与广播

本题为原创训练题。先修：先完成 P020；本题新概念见下方‘开始前先读’。

## 任务

对同一个 r×c 矩阵做两种独立加法：第一块将长度c的向量按列加到每一行；第二块将长度r的向量按行加到每一列。两块都从原矩阵计算，展示广播方向差异。

## 开始前先读

`a[i,:]` 中冒号表示取该行全部列；`a[:,j]` 表示取该列全部行。广播从最右边维度对齐，两个尺寸必须相等或其中一个为1。矩阵(r,c)加向量(c,)时，向量沿各行重复。行偏移(r,)不能直接当成(r,1)：先reshape((r,1))，右端的1才能扩展到c列。广播是运算规则，不要求手工复制数组。

## 输入输出与约束

第一行 r c；接着 r 行矩阵；再一行c个列偏移量；最后一行r个行偏移量。先输出第一块r行，再输出第二块r行，中间没有空行。

1 ≤ r,c ≤ 30，所有输入绝对值≤10000。输出每行c个数，总计2r行。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `float`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
2 2
1 2
3 4
10 20
100 200
```

输出：

```text
11 22
13 24
101 102
203 204
```

手算：A=[[1,2],[3,4]]。列偏移[10,20]：第一列各加10、第二列各加20，得到[[11,22],[13,24]]。行偏移[100,200]变为[[100],[200]]：第一行各加100，第二行各加200，得到[[101,102],[203,204]]。第二块不接着第一块相加。
