# P003 字符串拼接

本题为原创训练题。先修：先完成 P002；本题新概念见下方‘开始前先读’。

## 任务

读取姓名和学习内容，拼成一行“姓名正在学习内容”。两侧输入中的空格应保留，空姓名或空学习内容也是合法输入。

## 开始前先读

`str` 是字符串类型，`input()` 的结果本来就是 str，因此本题不调用 int。`name = input()` 读取一整行且去掉末尾换行，行内空格仍然保留。两个字符串之间的 `+` 表示拼接：`"A" + "B"` 得到 `"AB"`。`""` 是长度为零的字符串，也能参与拼接。

## 输入输出与约束

输入恰好两行字符串，第一行姓名，第二行内容。输出一行：第一行文字 + 正在学习 + 第二行文字。

每行长度 0–100 个字符，可含中文、英文和空格；不含换行符本身。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `text`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
小明
Python
```

输出：

```text
小明正在学习Python
```

手算：第一行“小明”、第二行“Python”，先把“小明”和“正在学习”连成“小明正在学习”，再接上“Python”，得到“小明正在学习Python”。若姓名是“李 华”，中间那个空格不能删掉。

## 三级提示

<details><summary>提示1</summary>

把输出分成输入文字、固定文字、输入文字三段。

</details>

<details><summary>提示2</summary>

三段都是字符串，所以可以使用两次 + 连接。

</details>

<details><summary>提示3</summary>

先读取 name 与 subject，再输出 name + 固定字符串 + subject。不要对输入做 split。

</details>
