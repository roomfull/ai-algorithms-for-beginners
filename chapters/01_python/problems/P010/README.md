# P010 集合去重计数

本题为原创训练题。先修：先完成 P009；本题新概念见下方‘开始前先读’。

## 任务

读取一行整数，求不同数值的个数。集合只用于消除重复，本题不要求输出集合元素或它们的顺序。

## 开始前先读

集合 set 保存不重复的元素，`set()` 创建空集合。注意 `{}` 已用于空字典。`seen.add(x)` 将元素放入集合；重复加入不增加元素数。先把输入文字转成整数，再去重，才能按数值比较。`len(seen)` 得到集合的元素数。集合不是按输入位置取值的列表，不用 seen[0]。

## 输入输出与约束

输入一行整数，空格分隔。输出一行不同整数数量。

1–1000 个整数，数值在 [-10000,10000]；1 与 01 表示相同整数。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `int`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
1 2 1 3 2
```

输出：

```text
3
```

手算：输入1 2 1 3 2：依次加入后集合大小为1、2、2、3、3，所以输出3。输入-1 1 -1 0：不同值为-1、1、0，共3个。
