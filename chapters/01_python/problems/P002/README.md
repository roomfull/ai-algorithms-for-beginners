# P002 变量与四则运算

本题为原创训练题。先修：先完成 P001；本题新概念见下方‘开始前先读’。

## 任务

读取两个整数 a、b，依次输出 a+b、a-b、a*b、a/b，每个结果占一行。先把读入行当作已经提供的工具，重点体会变量保存值以及表达式计算；不必一开始背下输入写法。

## 开始前先读

变量名是给值贴的名字。`a = 8` 的 `=` 表示把右边的值交给左边的名字，不是数学等式。`input()` 每次读一行文字；`int(...)` 把表示整数的文字转成整数；所以 `a = int(input())` 是从内向外先读、再转换、再命名。这两行已写在练习里，P004 再集中练转换。`+ - * /` 分别表示加、减、乘、真除法。`print(a + b)` 先算括号内再输出。

## 输入输出与约束

输入两行，第一行整数 a，第二行非零整数 b。输出四行，分别是和、差、积、真除法的商。

-1000 ≤ a,b ≤ 1000，b ≠ 0。允许负数和零；除法输出可为小数。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `float`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
8
2
```

输出：

```text
10
6
16
4
```

手算：a=8、b=2 时，8+2=10，8-2=6，8×2=16，8÷2=4。Python 的 `/` 会得到浮点数，显示为 4.0 也正确；换成 a=3、b=4 时商为 0.75。
