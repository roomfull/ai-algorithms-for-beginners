# P004 input 与数值转换

本题为原创训练题。先修：先完成 P003；本题新概念见下方‘开始前先读’。

## 任务

商店有 n 件同价商品，每件价格 p 元。读取整数件数和小数单价，计算总价 n×p，只输出数值。

## 开始前先读

类型决定运算含义。`int` 表示整数，`float` 表示浮点数，`str` 表示文字。`int('3')` 为 3，`float('2.5')` 为 2.5；`int('2.5')` 会报 ValueError，因为它不是整数字面文字。`input()` 不会根据你输入的样子自动选择类型，也不要在括号里放‘请输入’，那会污染标准输出。

## 输入输出与约束

输入两行：非负整数 n、非负实数 p。输出一行总价，不附加元字或其他文字。

0 ≤ n ≤ 10000，0 ≤ p ≤ 10000。无需财务舍入；浮点比较容差为 1e-6。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `float`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
3
2.5
```

输出：

```text
7.5
```

手算：件数文字 '3' 转成整数 3，单价文字 '2.5' 转成浮点数 2.5；3×2.5=7.5。若件数为 0，即使单价是 8.1，总价也为 0。
