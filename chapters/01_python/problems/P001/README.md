# P001 第一行固定输出

本题为原创训练题。先修：无；从本章开头的终端与文件说明开始。

## 任务

让程序只输出一行 `Hello, Python!`。大小写、逗号、空格和感叹号必须一致。这只是输出格式练习，程序不读取任何输入；五个案例用不同的被忽略 stdin 验证这一点。

## 开始前先读

先把文件理解为按顺序写下的指令。`print(...)` 是 Python 自带的输出操作；括号内是要显示的内容。英文双引号圈住的是字符串，即原样保存的文字；引号本身不会打印。`#` 到行尾是注释，只给人看。请用英文标点，中文引号不是代码中的引号。

## 输入输出与约束

输入：无须读取；即使存在输入也忽略。输出：一行固定文本 `Hello, Python!`。

不对 stdin 作任何假设；标准输出只有指定的一行。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `text`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
（空输入；不要输入这一行说明）
```

输出：

```text
Hello, Python!
```

手算：这题没有数字计算。`print` 取出引号内的 14 个字符：Hello（5）+逗号（1）+空格（1）+Python（6）+感叹号（1），然后自动换行。输入为空或为 abc 时，输出完全一样。
