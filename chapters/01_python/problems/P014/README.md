# P014 多组数据输入输出验收

本题为原创训练题。先修：先完成 P013；本题新概念见下方‘开始前先读’。

## 任务

进行一次考试式输入输出验收：输入 T 组数据，每组是一行整数；对每组独立求和并输出。不要输出组号、提示语或中间步骤。

## 开始前先读

本题不增加新语法，练习把‘读取组数→重复读一组→重置状态→计算→输出’连起来。`range(T)` 依次给出0到T-1，共T次；循环变量只用于控制次数，不要输出它。输入文件的换行是分组边界，因此每轮恰好调用一次 input 读这一组，而不是把整个文件混成一行。

## 输入输出与约束

第一行正整数 T；接下来恰好 T 行，每行是一组非空整数序列。输出恰好 T 行，对应各组总和。

1 ≤ T ≤ 100；每组1–1000个整数，每数在 [-10000,10000]。无需处理输入不合法或缺行。

标准输出只包含要求的结果。数值题允许等值的常见数值写法；行数与每行个数仍必须符合要求。本题比较模式为 `int`。

## 完整样例

输入（与 cases.json 第一个案例一致）：

```text
2
1 2 3
-1 5
```

输出：

```text
6
4
```

手算：T=2，第一组1 2 3求和为6；第二组-1 5必须重新从0开始，得到4。因此输出6、4两行，而不是6、10，也不把最前面的2当作数据参与求和。
