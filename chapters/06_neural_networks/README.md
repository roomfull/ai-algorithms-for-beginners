# 第 06 章：神经网络的前向、损失与一次更新

先完成[机器学习](../05_machine_learning/README.md)，特别是sigmoid、自然对数、损失、梯度与学习率。本章先算小矩阵，再算小图像，最后用4个标量参数理解GAN交替更新。不要求GPU、外部图片或完整GAN训练。

## 矩阵形状与全连接层

一个批次n个样本，每个d个特征，X形状n×d。o个输出神经元，每个接收d个输入，因此W形状d×o；b有o项。`Z=XW+b`形状n×o，b按每行相同方式相加。

例如X=[[1,2],[-1,3]]，W=[[1,-1],[2,0]]，b=[0,1]。第一样本的第一输出1×1+2×2+0=5，第二输出1×(-1)+2×0+1=0；第二样本输出(5,2)。这里不是逐元素相乘，内积需要求和。

ReLU(z)=max(0,z)是一种激活函数，把负值截成0。输入(-2,0,3)得到(0,0,3)；它不会把正值变成概率。[P051](problems/P051/README.md)实现全连接+ReLU。列表二维矩阵可直接用循环；如已学NumPy，也要能解释矩阵乘法每一项的含义。[numpy-ml层实现与文档](https://github.com/ddbourgin/numpy-ml)供核对。

## softmax与类别概率

多分类常把一行logits变成概率：`p_j=exp(z_j)/Σexp(z)`。z=(0,1)给约(0.269,0.731)，概率和1。每行单独归一化，各列对应固定类别；多样本不能混在一起求一个总和。

直接exp(1000)会溢出。减本行最大值m后，所有指数共同除以exp(m)，比例不变：`p_j=exp(z_j-m)/Σexp(z_t-m)`。z=(999,1000)和(0,1)得到相同概率。减最大值是等价变形，并非把分数裁到某个范围。[P052](problems/P052/README.md)同时检验大分数、单类与每行归一化。

## 损失与clip：概率形式和logit形式

损失是用来衡量输出与真实标签差异的数。二分类BCE正例损失-ln p、负例-ln(1-p)；多分类真实类别t损失-ln p_t。例如二分类两行(1,0.8)、(0,0.6)，正确类别概率0.8、0.4，平均损失约0.569717；多分类真实类概率0.8、0.75，平均CE约0.255413。[P053](problems/P053/README.md)读取这两种概率数据。

ln0没有有限值，所以概率输入题先clip到[eps,1-eps]。eps=0.01时，正例p=0的损失是-ln0.01≈4.60517；p=1的损失是-ln0.99≈0.01005。eps改变边界损失，不是无影响的打印处理。多分类只取真实类概率并clip，不把整行重新归一化。

训练题P054、P058采用稳定logit损失，避免clip改变导数：softplus(t)=max(t,0)+ln(1+exp(-|t|))。这与原损失数学等价。对已经clip的损失，不能在clip饱和区域仍盲目套原BCE梯度。

## 链式规则与一次训练

链式规则用于多个计算串联：若L依赖p，p依赖z，z依赖w，则 `∂L/∂w=(∂L/∂p)(∂p/∂z)(∂z/∂w)`。对sigmoid+BCE，前两项乘积简化为p-y；又z=w·x+b，所以∂z/∂w_j=x_j、∂z/∂b=1。最终梯度是(p-y)x_j和p-y。

一条正例x=(2,-4)，旧w=(0,0)、b=0，z=0、p=0.5，残差-0.5。权重梯度(-1,2)、偏置梯度-0.5。lr=0.1时新w=(0.1,-0.2)、b=0.05。两条以上样本先求平均梯度，再一起更新参数。[P054](problems/P054/README.md)只执行一轮，输出旧损失与新参数；与P047的最终损失输出时点不同。

ReLU在z>0的导数为1，在z<0为0，在0处需约定一个导数；本章仅做ReLU前向，不考查该不可导点的反向传播。有限差分可以独立验证光滑损失的梯度，不应只拿同一实现重复计算“预期”。

## 二维卷积：位置、核方向与尺寸

图像是h×w矩阵，核是kh×kw的小矩阵。深度学习常说的卷积实际上使用不翻转核的互相关；本章固定该定义。输入1..9的3×3矩阵与核[[1,2],[3,4]]，左上窗口计算1×1+2×2+4×3+5×4=37，右上47，左下67，右下77。[P055](problems/P055/README.md)用非对称核检验方向。

stride s表示窗口起点一次移动几格；padding p是在四边补p层0。输出高 `(h+2p-kh)//s+1`，宽同理。h=3、kh=2、s=2、p=0时高为1，末尾不足核大小的部分舍弃。padded下标从0开始，输出(i,j)窗口起点是(i*s,j*s)。[PyTorch Conv2d定义](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv2d.html)确认使用互相关；课程无需PyTorch。

```python
# 每个输出位置，内层遍历核。
value += padded[i*stride+a][j*stride+b] * kernel[a][b]
```

## CNN前向链与最大池化

本章简化CNN是“互相关+偏置→ReLU→最大池化”。池化窗口没有权重，取最大元素。输入[[-1,2],[3,-4]]、1×1核1、偏置0，ReLU变[[0,2],[3,0]]，2×2窗口池化得到3。

卷积stride s与池化stride ps分别控制各自起点。卷积尺寸H×W，池化窗口ph×pw后输出高 `(H-ph)//ps+1`，宽同理；本题池化不padding。[P056](problems/P056/README.md)只输出最终池化矩阵。最大池化一般损失位置和数值信息，不能从一个3恢复完整2×2输入。

## 转置卷积：每个输入散射一个缩放核

普通互相关将窗口收集到一个输出；转置卷积把每个输入乘核散射到多个输出，重叠处累加。输入[[1,2],[3,4]]与核[[1,2],[3,4]]，s=1、p=0时输出3×3；中心收到1×4、2×3、3×2、4×1，合计20。第一行(1,4,4)，第二行(6,20,16)，第三行(9,24,16)。

输入位置(i,j)的核元素(a,b)写到 `(i*s-p+a,j*s-p+b)`；越界项丢弃。高度 `(h-1)*s-2p+kh`，宽度同理。这是output_padding=0、dilation=1的特例；不能使用普通卷积的尺寸公式。[P057](problems/P057/README.md)覆盖重叠、stride、裁边与矩形核。

把普通互相关写成展平向量的线性关系y=A x，转置卷积相当于Aᵀu。匹配尺寸时 `Σ(Ax)_i u_i=Σx_j(Aᵀu)_j`，独立测试用显式矩阵核对这个恒等式。Aᵀ一般不等于A逆矩阵；扩大尺寸不能保证还原原图。stride>1时原输入形状还可能不唯一，本题明确不处理output_padding。[PyTorch ConvTranspose2d说明](https://docs.pytorch.org/docs/stable/generated/torch.nn.ConvTranspose2d.html)也区分转置与逆运算。

## GAN：两个模型、两个目标、两次更新

生成器G尝试产生像真实数据的样本；判别器D输出“是真样本”的概率。为可手算，本题只用G(z)=a*z+g，D(x)=sigmoid(w*x+b)，真实数据xr、噪声z都只有一个数。这里学习的是交替优化流程，不是训练逼真图像。

先固定G，使D把真样本判为1、假样本判为0，最小化 `L_D=-ln D(xr)-ln(1-D(G(z)))`。这里两项求和，没有除2。令p_r=D(xr)、p_f=D(fake)，梯度 `d_w=(p_r-1)*xr+p_f*fake`、`d_b=p_r-1+p_f`。

再固定更新后的D，使G的假样本被判为真，采用非饱和生成器损失 `L_G=-ln D_new(G(z))`。令p_new为新D对旧fake的概率，生成器梯度 `d_a=(p_new-1)*w_new*z`、`d_g=(p_new-1)*w_new`。每一步参数都同时更新；G步不再改D。[GAN原论文](https://arxiv.org/abs/1406.2661)说明对抗目标与非饱和训练策略，本题公式以题面为准。

手算xr=z=1、a=g=w=b=0、两学习率均1：fake=0、p_r=p_f=0.5，L_D=2ln2；D梯度(-0.5,0)，新(w,b)=(0.5,0)。G使用新D，L_G=ln2，梯度(-0.25,-0.25)，新(a,g)=(0.25,0.25)。若用了旧w=0，G梯度变0，会漏掉真实交替更新。[P058](problems/P058/README.md)同时检验损失和参数。

标准minimax生成器目标是ln(1-D(G(z)))；本题使用非饱和目标-ln D(G(z))，不能把两者的梯度混用。输出L_D的时点是D更新前，L_G的时点是D更新后、G更新前。
