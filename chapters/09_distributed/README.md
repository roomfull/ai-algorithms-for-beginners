# 第09章：从分片到同步SGD的数值模拟

本章接在梯度与SGD之后。你已经知道单个参数更新 `theta_new=theta-lr*gradient`；现在讨论同一批数据被多个worker处理时，怎样得到同一个全局梯度。练习全部在一个Python程序中读入小向量、做归约，不启动多进程、网络通信或GPU。worker只是被编号的计算参与者。

## 1. 什么是worker和全局batch

worker可以理解为“负责某一片数据的人”。真实训练中它可能是进程或设备；这里用编号0,1,...表示，每个worker得到一组样本。所有worker这一轮处理的样本合起来，叫全局batch。

比如6个样本，worker0处理2个，worker1处理4个，全局batch大小6。每个worker计算相同参数位置的梯度向量；二维梯度(2,-1)表示参数theta[0]导数为2，theta[1]导数为-1，不能把两坐标先平均成一个标量。

同步训练要求这一轮所有局部梯度都对应同一个旧参数theta，聚合后每个worker再采用同一个新参数。若worker之间使用的参数已经不同，局部梯度即使做加权平均，也不能直接视作一个固定theta上的全局大batch梯度。

## 2. 连续均衡分片与半开区间

P077把编号0..n-1的样本连续分片，用 `[start,end)` 表示：包括start，不包括end，所以长度为end-start。Python的 `range(start,end)`和列表切片也是这个约定。空片 `[2,2)` 不包含任何样本。

n=10，workers=3，`divmod(10,3)`得到商3、余数1。每个worker先3个，多出的1个给最前面的worker：

| worker | 区间 | 样本编号 | 数量 |
|---|---|---|---|
| 0 | [0,4) | 0,1,2,3 | 4 |
| 1 | [4,7) | 4,5,6 | 3 |
| 2 | [7,10) | 7,8,9 | 3 |

输入n=2、workers=4时，长度是1,1,0,0。不要强行给每个worker至少1个，否则会越界。分片必须覆盖0..n-1一次、相邻区间首尾接上、最大长度与最小长度之差≤1；这些是比单一样例更有用的检查性质。

实际训练还可能要洗牌、补齐、重复样本或丢弃尾批，这些都需要明确新的采样规则；本题采用连续分片且每样本一次，以便先理解分工与边界。

## 3. 局部梯度平均与全局平均

记第w个worker有c_w个样本，它给出的g_w是这些样本梯度的平均。局部梯度和就是 `c_w*g_w`。全局按样本取平均应为：

`global_grad = sum(c_w*g_w) / sum(c_w)`。

所有c_w相等且正数时，公共因子约掉，得到 `sum(g_w)/workers`，即P078的简单平均。样本数不等时，每个worker对全局的影响应与其样本数成比例，这才是P079。

用一个标量反例：worker0仅1个样本，梯度1；worker1有3个样本，梯度都为5，因此其局部平均5。简单worker平均是(1+5)/2=3，而四个样本的平均是(1+5+5+5)/4=4。前者把单个样本放大成与三个样本同等的影响。

| 情况 | 合法分母 | 输入的梯度含义 |
|---|---|---|
| 等样本worker简单平均 | worker数 | 每个worker的局部均值 |
| 不等样本加权归约 | 总样本数 | 先乘对应样本数恢复局部和 |
| 已经给出局部梯度和 | 总样本数 | 不应再次乘样本数；本章题面不采用此输入 |

零样本worker的权重为0，输入的占位梯度不应影响结果。仍要读完整行，防止后续输入错位。总样本数必须大于0，才能定义全局平均。

## 4. Microbatch与梯度累积

microbatch是为了分块处理而把一个局部batch再切小。例如worker0有4样本，可能切成1样本和3样本两批。P080输入的是每个microbatch的样本数c以及平均梯度g，不是梯度和。

累积步骤是“乘样本数、求和、最后归一化”：每批增加 `c*g`，跨worker把所有这些和再求和，总样本数也求和。只在最后除全局总样本数一次。按microbatch个数平均仅在每批样本数完全相同等特定条件下才正确。

手算例：worker0两批分别1样本梯度2、3样本梯度4，worker1一批2样本梯度8。总梯度和2+12+16=30，总样本1+3+2=6，全局平均5。theta=10、lr=0.1，则新参数9.5。

如果先把worker0两批简单平均成3，再与worker1的8平均，会得到5.5；如果正确得到5后再除worker数2，会变成2.5；两种错误都破坏样本权重。

累积阶段要保持theta不变。按每个microbatch连续更新多次，是另一条优化轨迹，后续梯度往往已经对应新的参数。本题所有梯度已给定并来自同一个旧theta，因此更新只执行一次，和固定参数处的完整全局batch平均梯度等价。

## 5. 把计算写成清楚的循环

可以为每个参数维护一个梯度和 `total[j]`，再维护整数 `count_sum`。循环结构是worker→microbatch→参数坐标，更新total与count_sum。所有批读完后产生gradient，最后更新theta。梯度vector的长度是dims，分母没有dims。

标准库Fraction让输入小数求和与更新保持精确：`Fraction('0.1')`是1/10。输出再转float保留12位有效数字。真实训练通常采用浮点张量；本题精确有理数只是在小规模教学输入下避免不必要的舍入干扰，不表示实际训练必须使用Fraction。

P078/P079时间O(workers*dims)，P080令B为microbatch总数，时间O(workers+B*dims)。当前实现先 `raw.split()`，因此输入tokens占O(workers+B*dims)空间；归约数组本身仅O(dims)。不要把后者误写为整程序总空间。

## 6. 数值模拟与真实DDP的联系

真实分布式系统需要协调进程、同步参数、通信梯度、处理设备和故障。PyTorch DistributedDataParallel的教程可在[一手文档](https://docs.pytorch.org/tutorials/intermediate/ddp_tutorial.html)阅读；本章借它核对同步梯度的基本概念，代码不调用DDP，也没有网络性能或加速比实验。

局部loss是样本和还是样本均值、各worker batch大小是否一致、通信操作求和还是平均，都会决定最终比例。不能只看到“all-reduce”就断言分母。本课程题面固定为局部样本均值，并由全局样本加权定义所需结果。

大batch等价也有条件：本题假设样本梯度在相同参数处计算、可以按样本相加。含BatchNorm等依赖批内统计的模型、随机操作或不同损失归约时，分块前向本身可能改变梯度，不能把本章给定梯度的数学等价扩展为所有真实训练都完全相同。
