# 第07章：用点和边理解图算法

先学完列表、字典、集合、函数与循环；本章全部用Python标准库。图不是图片文件：它由顶点（vertex，也叫节点）和边（edge）组成。道路站点是点，站点之间的道路是边；网页是点，链接是有向边。练习用0到n-1给点编号，编号只是名字，没有距离含义。

## 1. 从一条边到邻接表

无向边0—2表示两端都能互相到达；有向边0→2只说明从0能去2。权重是经过边的代价，整数2可以表示成本2；权重与顶点编号是不同概念。简单无向图没有自环（自己连自己）和重边（同一无向边出现两次）。有向题P060、P068、P069允许自环，具体保证以题面为准。

假设四个点有边0—1、0—2、2—3，邻接表如下：

| 点 | 邻居 | 无向度数 |
|---|---|---|
| 0 | 1,2 | 2 |
| 1 | 0 | 1 |
| 2 | 0,3 | 2 |
| 3 | 2 | 1 |

Python可以用 `adj=[[] for _ in range(n)]` 创建n个独立列表。不要写 `[[]]*n`：里面会多次引用同一个列表，给一个点添加邻居会改掉全部行。无向边在两端各append一次；有向边只登记起点到终点。使用集合 `set()` 能快速判断边是否存在；列表适合保存邻居并遍历。邻接矩阵占O(n²)位置，邻接表在稀疏图中通常占O(n+m)。

无向图所有度数之和为2m；有向图的入度之和与出度之和各为m。这两个等式很适合排查漏登记或方向写反。入度指进入自己的边数，出度指离开自己的边数。一个孤立点没有边，但仍是一个顶点，必须参与输出。

## 2. 路径、队列、栈与“访问过”

路径是连续经过相邻点的过程；0→2→3需要两条边。连通分量是一组互相可达的点。没有边的孤立点也单独构成一个分量。

队列先进先出，像排队：先到的先被处理。Python用 `collections.deque`，入队 `append`，出队 `popleft`。列表 `pop(0)`要搬移后面元素，单次O(队列长度)，会破坏BFS的线性复杂度。

栈后进先出，像叠盘子：最新放上的最先取。Python列表的 `append` 和末尾 `pop` 可以作栈。在本章规模下这两操作摊还O(1)。

搜索需要 `visited` 或距离/颜色标记。图可能有环，如果不标记，0→1→0会无限重复。首次发现并准备入队/入栈时就标记，保证每个点只进入一次。

## 3. BFS与DFS分别解决什么

BFS（广度优先）先处理起点，再处理离起点1条边的点，再处理2条边的点。上面的图从0搜索，距离是 `[0,1,1,2]`；若多一个孤点4，其距离为-1。这一结论要求所有边的代价都等于1；加权图不能直接拿BFS层数当最小权重和。

DFS（深度优先）沿一条分支尽量向下，再回到其他分支。显式栈从0开始，具体访问顺序会受邻居顺序影响，但最终找到的可达点集合相同。P062只输出分量编号，按最小顶点顺序给分量编号，使结果稳定。外层必须扫描全部点，单次从0出发会漏掉不连通部分。

| 目标 | 适用工具 | 为什么 |
|---|---|---|
| 无权最短边数 | BFS队列 | 按距离层数扩展 |
| 可达性、连通分量 | BFS或DFS | 都能走完整个分量 |
| 路径上的分支探索 | DFS栈 | 先深入最新分支 |
| 边动态合并后的连接查询 | 并查集 | 维护集合而不是反复搜索 |

BFS/DFS遍历邻接表各看每个点一次、每条边常数次，所以O(n+m)。无向图边在邻接表中出现两次，这只改变常数。

## 4. 并查集与最小生成树

并查集（DSU）给每个点一个父指针parent，沿指针直到 `parent[x]==x` 就到根；根代表当前集合。合并只能把一个根接到另一个根，不能随意连接内部点。查询比较两个根。

路径压缩把查找路上的点更靠近根；按大小合并把小集合挂到大集合下。二者组合后操作摊还非常快，常记为O(α(n))，这里α增长极慢。它维护连接关系，并不保存具体道路，也不能回答最短距离。

生成树必须覆盖所有点、无环、恰好n-1条边。最小生成树（MST）使边权总和最小。单点的生成树没有边，总权重0；不连通图不存在覆盖所有点的生成树，本章输出 `DISCONNECTED`。

Kruskal把边从便宜到昂贵排序，若两端已属于同一集合就跳过，否则合并并选边。Prim从一个点开始，用最小堆不断选跨越已加入点集和外部的最便宜边。Python `heapq`是最小堆；可以有多个旧候选通往同一点，出堆时跳过已经加入的点。

两种算法的贪心选择来自MST的割性质：对一个分割，跨割的最小权边可以属于某棵MST。这里负权也合法；例如权重-3与1的树总重-2。等权时最优树不一定唯一，但总重相同。实现来源可核对 [TheAlgorithms 的 Kruskal](https://github.com/TheAlgorithms/Python/blob/master/graphs/minimum_spanning_tree_kruskal.py)；本课程答案独立实现。

## 5. 三角形与二分图

三角形要求三点间的三条边都存在。只枚举a<b<c，能让每组三点计一次。四点完全图有 `C(4,3)=4` 个三角形。本章直观三点枚举O(n³)，不是面向亿级图的优化实现。

二分图可把点染成两种颜色，让每条边连接异色点。BFS发现邻居时涂相反色，发现同色边则失败。必须检查所有分量；孤立点任选颜色即可。三角形是奇环，因此有三角形不能二分；没有三角形仍可能有五边奇环，不能直接推出二分。

## 6. PageRank把图变成概率流

给每个点一个概率p，总和为1。一个有出边的点把自身概率平均沿出边传出；没有出边的点叫悬挂点（dangling node），本章让它均匀分给全部点。阻尼alpha控制沿图移动的比例，其余1-alpha为均匀传送。

每轮都从旧数组p建立新数组q：

`q[v]=(1-alpha)/n+alpha*(来自有出边点的流入+dangling_mass/n)`。

例如2点仅0→1，p=(0.6,0.4)，alpha=0.8。每点传送0.1，悬挂点1均分贡献0.16；点0向1再传0.48，所以q=(0.26,0.74)，总和仍1。原地覆盖p会让本轮后半段使用新值，破坏同步更新定义。

P069从均匀分布开始，每次完整更新后计算L1差 `sum(abs(q[i]-p[i]))`，差≤tol即停止；到max_iter仍不满足要标记未收敛。本章阈值就是tol；[NetworkX的PageRank源码](https://networkx.org/documentation/stable/_modules/networkx/algorithms/link_analysis/pagerank_alg.html)使用其自身的n*tol规则，不能把库的约定直接抄进本题。

P069为精确收敛边界限定n≤20、m≤100、max_iter≤200，使用标准库Fraction从原小数字符串读取alpha和tol，均匀初值用Fraction(1,n)，概率与L1全程保留有理数，只在输出时转float。例如alpha=0.02的两点0→1，首轮是(0.495,0.505)，L1精确等于0.010，必须判收敛；阈值0.009999则不收敛。不能给阈值加epsilon，否则会改变题目定义。Fraction的分母位数随轮数增长，因此O(K(n+m))只是有理数操作次数，实际还需计大整数运算成本；P068仍是浮点单轮示范，真实大图常用浮点迭代。
