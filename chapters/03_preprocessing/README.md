# 第 03 章：预处理

本章把原始数据整理成可用于算法的数值。完成[第 02 章](../02_math_numpy/README.md)后再进入。这里仅使用 Python 标准库，读入小矩阵后自己实现算法，不需要下载数据或安装机器学习框架。每一行是一条样本，每一列是一个特征，例如身高与体重是两列，不能混合求同一个平均值。

先读教程再做题；先自己写 `exercise.py`，提示可以逐级展开，题解是对照材料。所有题均为原创练习。

## 1. 均值、中位数与缺失值

算术均值是总和除以个数。数据 `1,3,8` 的均值是 `(1+3+8)/3=4`。若 `1,NA,3` 中 `NA` 表示未知，已知总和4，有效个数2，填补均值是2。不能先把NA当0再除以3。整列未知无法估计均值，P023明确回退0；实际任务中还需考虑这一列是否有保留意义。

中位数要先排序：`8,1,3` 排为 `1,3,8`，中位数是3；`1,2,3,100` 有偶数个，中位数为中间两个值的平均 `(2+3)/2=2.5`。均值是26.5，会受100明显影响。第04章将用中位数定义MAD。

矩阵 `[[1,NA],[3,4],[NA,8]]` 的两列分别填2和6，结果是 `[[1,6],[3,4],[2,8]]`。[P023 均值填补](problems/P023/README.md)练习有效计数和全缺失列；可把每列看作单独的数字列表。[缺失值定义核对](https://scikit-learn.org/stable/modules/impute.html)。

## 2. 去重与顺序

样本 `[2,1]` 和 `[1,2]` 不同，因为列含义不同。重复行 `[2,1]` 再出现时只保留第一次。集合 `set` 能快速判断是否见过，但不能承担题面要求的顺序；同时使用一个结果列表。

```python
seen = set()
kept = []
for row in rows:
    key = tuple(row)       # 元组可作为集合元素；列表不能
    if key not in seen:
        seen.add(key)
        kept.append(row)
```

[P024 稳定去重](problems/P024/README.md)要求输出数目和保留行，练习观察输出的形状。[Python集合说明](https://docs.python.org/3/library/stdtypes.html#set-types-set-frozenset)。

## 3. Min-Max缩放

对同一列，公式是 `z=(x-min)/(max-min)`。`0,5,10` 对应 `0,0.5,1`；`-4,-2,0` 也对应 `0,0.5,1`，所以负数不是特殊情况。如果每个值都是7，分母0，P025把整列输出为0。

Min-Max改变单位和范围，但保留该列数值的相对线性关系，不能自动消除异常值。一个极大的数会把其他值压在很小的范围。[P025 列缩放](problems/P025/README.md)重点是逐列统计和0分母分支。[官方缩放定义](https://scikit-learn.org/stable/modules/preprocessing.html#scaling-features-to-a-range)。

## 4. 方差、标准差与Z-score

平均值描述中心，方差描述离散程度。对 `2,4`，均值3；偏差为 `-1,1`，平方偏差为 `1,1`，总体方差 `(1+1)/2=1`，标准差是方差开平方，为1。Z-score是 `(x-均值)/标准差`，得到 `-1,1`。

对 `-1,0,1`，总体均值0、方差 `2/3`、标准差 `sqrt(2/3)`，结果约 `-1.224745,0,1.224745`。验证时计算输出均值约0、总体平方均值约1，不能期待每个输出都在[-1,1]。

总体方差使用n作分母；统计学的样本方差常用n-1，这是另一个定义。[P026 Z-score](problems/P026/README.md)明确用总体定义，常量列输出0。标准化只改变中心和尺度，不保证变成正态分布。[官方标准化说明](https://scikit-learn.org/stable/modules/preprocessing.html#standardization-or-mean-removal-and-variance-scaling)。

P025–P027的数值使用普通十进制写法（不使用指数），小数点后最多12位，仍保留题面的大小和样本数限制。浮点数不能精确表示一些十进制小数：`999999.999992,999999.999993,999999.999994`等间距，Min-Max中间值应恰好是0.5；先转float再相减会破坏小差值。标准化同样会放大误差，只检查常量列不能解决非零窄范围。

使用Python标准库的有理数：`from fractions import Fraction`，然后`Fraction("0.1")`得到精确的1/10。不能写`Fraction(float("0.1"))`，那会保存已经舍入的数。P025/P027的最小最大值、差值、除法都用Fraction，最后`float(result)`再格式化；P027仍只使用训练行拟合。

P026精确求均值μ、总体方差v，v=0时输出0。v>0时，令δ=x-μ，利用 `(δ/sqrt(v))²=δ²/v`，先精确求δ²/v，再`math.sqrt(float(δ*δ/v))`，最后按δ的符号恢复正负。这样避免先将很小的原始方差转成float下溢；该无量纲比值在0到n之间，12位小数和有限数值范围也保证非零结果可表示。例如间距10^-12的0、10^-12、2×10^-12仍得到约-1.224745、0、1.224745。

Fraction会做大整数运算和约分，不能把任意位数运算都算O(1)。题解中的O(nd)统计有理数运算次数；若分子/分母最多B位，每个数还要O(B)位存储，每步付出相应大整数算术成本。这里限制小数位、大小和n，保持适合教学的小规模。[Python Fraction官方说明](https://docs.python.org/3.11/library/fractions.html)。

## 5. 先划分，后拟合，避免泄漏

训练集用于估计参数，验证集用于观察未参与拟合的数据上的表现。填补均值、缩放最小最大值、后面的词表与IDF也属于参数，应从训练数据拟合，再应用到验证数据。

若训练数据是 `0,10`，验证数据是 `100,5`，训练范围为[0,10]，四个变换结果是 `0,1,10,0.5`。如果先把验证100加入求最大值，训练10会变成0.1，训练结果已经受验证数据影响。这称为数据泄漏。验证结果超过1是合理的，表示超出训练范围。

[P027 给定顺序划分](problems/P027/README.md)不用随机数：给定下标排列，前t条训练，余下验证。输出按排列顺序；训练常量列全部输出0是本题明确的教学规则。[官方泄漏示例](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)。

## 6. 类别不平衡与复制过采样

分类标签可以是0与1。如果90条是0、10条是1，只预测0的程序就有90%的整体准确率，却完全漏掉1类。因此要按类观察表现，不能只看一个总比例。重采样是处理不平衡的可能方式，不保证一定提升模型。

[P028 确定性过采样](problems/P028/README.md)按目标数复制原样本。0类样本特征 `10,30`，目标5时，保留两条，再循环补 `10,30,10`。先输出所有原样本，再先补0类、后补1类。复制不会创造新的独立信息。

实际评估应只对训练部分重采样，验证集保留其任务分布；同一个原样本的复制若跨入验证集，会使评估失真。[官方过采样说明](https://imbalanced-learn.org/stable/over_sampling.html)。

## 7. 从线段插值到SMOTE

SMOTE在少数类点与其少数类邻居间生成新点。先理解[P029 线段插值](problems/P029/README.md)：`x_new=x+λ(z-x)`。基点 `(1,3)`、邻点 `(5,7)`，差为 `(4,4)`；λ=0.25时新点为 `(2,4)`。λ=0回到基点，λ=1到邻点；两个坐标共享同一个λ，才能在同一条线段上。

然后做[P030 完整小型SMOTE](problems/P030/README.md)。先识别少数类，再为每个少数类点查k个邻居。二维平方欧氏距离为 `(a0-b0)²+(a1-b1)²`。平方距离与距离大小顺序相同，所以排序不必开平方。自身不能作邻居；不同样本即使坐标相同，仍可作为邻居。

例如少数类输入索引0、1、2的坐标为 `0,-2,2`，多数类坐标为 `0.1,0.2,0.3,0.4`。基点0到-2和2的平方距离同为4，按原始索引，邻居顺序为-2、2。多数类0.1虽更近，却被排除。k=2，第0条生成用q=0、λ=0.5，得到-1；第1条基点-2，其邻居顺序为0、2，用q=1、λ=0.5，得到0；第2条基点2，用q=0、λ=0.5，得到1。

本题显式输入q与λ，基点循环选取，使手算和测试可复现。生成点不加入下一轮邻居搜索，类数并列的输入也不在本题范围。[官方插值定义](https://imbalanced-learn.org/stable/over_sampling.html#sample-generation)和[GitHub实现](https://github.com/scikit-learn-contrib/imbalanced-learn/blob/master/imblearn/over_sampling/_smote/base.py)用于核对思路；本题的确定性顺序由题面规定。

P030的坐标最多12位小数，邻居排序按输入十进制的精确距离决定。例如基点0.3到0.4与0.2都相距0.1，若0.4输入下标更小，应选0.4。先转float可能让两次减法有不同舍入误差，打破并列。因此参考解从原始文本创建标准库 `Fraction('0.3')` 等有理数，精确计算平方距离并排序；不要用 `Fraction(float('0.3'))`，也不要用模糊epsilon替换排序规则。选好邻居后才转float做允许误差的插值输出。
