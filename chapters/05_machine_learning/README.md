# 第 05 章：从样本到机器学习

先完成[特征工程](../04_features/README.md)。本章使用很小的数值数据，逐步实现KNN、K-means、逻辑回归与CART。所有答案是独立Python文件，只需标准库；无需下载数据集或安装sklearn。

## 样本、特征、标签与预测

一个样本是一条观测，例如一辆车；特征是可计算的输入，例如速度和车龄。两辆车各有两个特征时，特征矩阵X形状为2×2。标签是希望预测的答案，例如是否需要维修，用0、1表示。本章题面中“标签+特征”一行 `1 30 5` 表示标签1、特征(30,5)；标签不能放进距离计算，否则相当于提前看了答案。

分类使用带标签样本学习规则，再给新样本预测类别。聚类只有特征，按相似程度形成组，组编号没有“正确类别”的预设语义。KNN保留训练样本，预测时找邻居；逻辑回归训练权重；决策树训练分支阈值；K-means训练簇中心。

训练是根据训练数据确定规则或参数，预测是用已经确定的规则处理新输入。例如w=1、b=0时，逻辑回归可以直接预测x=2；要决定w是否应该变大，需要看训练标签和损失。本章P045练预测，P046练梯度，P047才执行完整多轮训练。实际评估应使用没有参与训练的新数据，预处理也沿用训练时拟合的参数。

## KNN：距离顺序与两种平局

欧氏距离是 `sqrt(Σ(x_j-q_j)²)`。非负平方距离排序与距离排序相同，可省开根号。查询(0,0)到(1,0)、(-1,0)、(0,2)的平方距离分别1、1、4；前两点同距时按原始下标排列。若三个标签为9、2、9，k=2时两类各1票，按本题规定取最小标签2；k=3时9有2票，预测9。

```python
distance = sum((x-q)**2 for x, q in zip(point, query))
# 排序使用(distance, index)，计票使用标签。
```

输入特征限定整数，平方和使用Python整数精确运算，避免把浮点误差误当成平局。k改变决策范围，不是学习率。KNN对特征单位敏感：速度数百、车龄个位时前者更影响距离，前面学的标准化可改变这种权重关系。[P039](problems/P039/README.md)排序，[P040](problems/P040/README.md)单查询投票，[P041](problems/P041/README.md)重复处理多个查询；每次重新计票。

## K-means：分配、平均与迭代

一维点0、2、8、10，初始中心0、10：最近中心分配为0、0、1、1；两个新中心是(0+2)/2=1、(8+10)/2=9。再次分配和更新不变，算法停止。所谓质心，就是一簇所有点每个坐标的平均，不是“最靠近中心的实际样本”。

SSE（误差平方和）是 `Σ||x_i-center[label_i]||²`。这个例子初始SSE=0+4+4+0=8，更新后是1+1+1+1=4。精确最近点分配与均值更新都不会增加SSE；本题用1e-12容差处理浮点距离并列，因此性质测试也容许很小数值误差。Lloyd算法可能依赖初始中心并停在局部结果，不能把一次训练称为全局最优。

若某中心没有点分到它，平均数分母为0；本题明确保留旧中心。例如点0、2，中心0、100：两点归中心0，更新成1，中心100保留。初值显式输入，不用随机种子。[P042](problems/P042/README.md)分配，[P043](problems/P043/README.md)更新，[P044](problems/P044/README.md)完整迭代。

P044每轮先分配再更新，以坐标最大变化≤tol判停；达到轮数上限也必须再按最终中心分配。点0、2、3、10，初始中心0、2，第一轮旧分配0、1、1、1，新中心0、(2+3+10)/3=5；最终边界2.5使点2改归簇0，标签变成0、0、1、1。不能沿用旧标签。

## 概率、自然对数与损失

概率p在0到1之间；p=0.8表示模型给类别1的概率是0.8，不表示这次一定正确。sigmoid将任意分数z映成 `1/(1+exp(-z))`：z=0给0.5，z=1约0.731，z=-1约0.269。分数由 `z=w·x+b` 得到，w每项对应一个特征，b是不随样本改变的偏置。[P045](problems/P045/README.md)固定参数预测。

自然对数ln在Python写 `math.log`，以e为底。ln1=0，ln0.5≈-0.693；正确类概率越小，负对数越大。正例y=1的BCE是 `-ln p`；负例y=0的BCE是 `-ln(1-p)`。两例(y,x)=(0,0)、(1,2)，w=b=0，p均0.5，平均损失ln2。平均时除的是样本数n。

直接取log概率可能遇到舍入后的log(0)。本章训练题采用稳定等价式 `softplus(z)-y*z`，其中 `softplus(z)=max(z,0)+log1p(exp(-abs(z)))`。它保持原损失，不靠裁剪概率。[P046](problems/P046/README.md)输出当前损失和梯度。

## 梯度与学习率：先手算一次

梯度描述“参数增加一点，损失怎样改变”。例如对一个参数w，用 `(L(w+h)-L(w-h))/(2h)` 可以近似导数；多个参数的各个导数组成梯度。梯度正时减小参数常能降低当前附近的损失，梯度负时增大参数常能降低损失。

sigmoid+BCE简化后的残差为p-y；权重梯度是平均 `(p-y)*x`，偏置梯度是平均p-y。上面两样本的残差0.5、-0.5，权重梯度(0.5×0-0.5×2)/2=-0.5，偏置梯度0。学习率lr=1时，w从0更新为0-1×(-0.5)=0.5，b仍0；新平均损失 `(ln2+ln(1+e^-1))/2≈0.503204434`，小于旧的0.693147。

全批量更新先计算所有样本的旧参数梯度，再一次改参数；逐样本改参数是另一种训练算法。本题执行固定轮数，不添加正则项。lr控制步长，大步可能越过合适位置，不能说损失永远下降。[P047](problems/P047/README.md)完成这个循环。

## 熵、Gini与连续特征分裂

类别0、1各占一半，Gini=`1-(1/2)²-(1/2)²=0.5`，熵=`-2×(1/2)log2(1/2)=1`。纯标签时两者0。本章熵用log2，前面交叉熵用ln；不要混淆。[P048](problems/P048/README.md)先练计数与不纯度。

一维特征0、1、2、3，标签0、0、1、1。候选阈值取相邻不同值中点0.5、1.5、2.5。用1.5切时左标签0、0，右标签1、1，两边纯，加权Gini=0。用0.5切时左单个0，右0、1、1，右Gini=4/9，加权为(3/4)×(4/9)=1/3，较差。权重是分支样本数占比，不能直接把两边Gini取平均。

[P049](problems/P049/README.md)枚举全部特征与阈值；并列按特征编号，再阈值升序。常量特征无候选；有候选但分裂不降低不纯度则叫无增益。两者都可能终止树训练，含义不同。

## 多层 CART：递归与停止

训练x=0..5，标签0、0、1、1、0、0。根最优阈值1.5、3.5同分，选择1.5。左边纯0；右边标签1、1、0、0，再以3.5分为纯1与纯0。树需要深度2才能预测中间区间为1；max_depth=1时右叶多数票平局，按最小标签预测0。[P050](problems/P050/README.md)实现这棵树。

```text
根：x≤1.5？
  是 → 标签0
  否 → x≤3.5？
          是 → 标签1
          否 → 标签0
```

根深度0，递归时深度加1；标签纯、达到最大深度、无候选、或增益≤1e-12就存叶标签。预测只沿一条分支走到叶。XOR四点(0,0),(0,1),(1,0),(1,1)，标签0,1,1,0时，任一单特征根分裂增益为0；本题规则会停在多数叶，贪心树没有自动解决全部数据的保证。[CART官方说明](https://scikit-learn.org/stable/modules/tree.html)用于核对定义，不调用库训练。
