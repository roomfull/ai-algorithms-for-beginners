# P012 函数与 return：题解

先尝试 [题目](../chapters/01_python/problems/P012/README.md)，再对照本页。

## 思路和关键步骤

函数定义保存规则，并不立即计算。两次调用各有独立的参数值，返回后由外层 print 输出。把逻辑与输出分开，使同一平方规则也能用于后续数学表达式。

## 再做一次手算

square(3) 内部计算3×3=9，并把9返回给 print；square(4) 返回16，最终两行9和16。square(-2) 计算(-2)×(-2)=4，平方不会保留负号。

## 复杂度

限定数值范围内，两次乘法时间 O(1)，每次调用固定大小，额外空间 O(1)。

## 易错点与自查

Python 的乘方运算是 **，^ 是按位异或。忘写 return 时函数默认返回 None；内部 print 之后外部再 print 会多出 None。

比较样例中间值，定位是读取、计算还是输出的错误。不要在最终stdout保留调试文字。
