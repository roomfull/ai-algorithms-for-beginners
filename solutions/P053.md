# P053 BCE 与多分类交叉熵题解

思路：输入的是概率。二分类先p←min(1-eps,max(eps,p))，算平均[-y ln p-(1-y)ln(1-p)]。多分类每行真实类别为t，只取它的概率p_t做同样clip，算平均[-ln p_t]；不重新归一化clip后的概率。本题clip上界也用于多分类，真实类概率1会产生很小正损失。 实现时可等价地先取真实类概率q（y=1取p，y=0取1-p），直接对q裁剪并求-ln(q)。q≤eps时直接用-log(eps)，q≥1-eps时用-log1p(-eps)，避免先构造1-eps再相减恢复eps或损失微小正确类损失精度。

关键步骤：二分类先取q=p if y==1 else 1-p；多分类取q=probs[target]。q≤eps返回-log(eps)，q≥1-eps返回-log1p(-eps)，其余返回-log(q)，最后按n平均。

样例核对：二分类(1,0.8)、(0,0.6)：正确类别概率分别0.8、0.4，BCE=-(ln0.8+ln0.4)/2≈0.569717142。多分类真实类概率0.8、0.75，CE=-(ln0.8+ln0.75)/2≈0.255412812。eps=1e-6未触发clip。

复杂度（对应参考实现）：时间 O(nc)，空间 O(nc+n)，解析全部概率行。

易错点：不能用argmax代替真实类概率；clip不重新归一化；eps改变边界损失，不能固定写死另一eps。 eps很小时1-(1-eps)不等于原浮点eps；直接对真实类概率clip，并为上下边界选稳定log公式。
