# P035 按秩等频分组题解

思路：本题采用按秩分组的等频教学规则：按 (值, 原始下标) 升序稳定排序；从0开始的秩 r 分到 floor(r*k/n) 号组；再恢复输入顺序。重复值按原始下标打破并列，同值可分到不同组，因此这不是只由数值边界决定的区间分箱。每组数量最多相差1，不保证完全相等。

关键步骤：排序 enumerate(values) 为 (value,index) 顺序；对秩r把 r*k//n 写入结果的原始index。

样例核对：排序后的(值,下标)为(1,1),(2,3),(3,2),(4,4),(5,0)；秩0、1、2归0，秩3、4归1；恢复后得到1 0 0 0 1。

复杂度（对应本参考实现）：时间 O(n log n)，空间 O(n)。

易错点：不能把同值全部放同一箱又声称严格等频；本规则可拆同值，与一些库的分位数边界实现不同；无法只靠箱边界给新值分组。
