# P008 列表筛选：题解

先尝试 [题目](../chapters/01_python/problems/P008/README.md)，再对照本页。

## 思路和关键步骤

每个 token 只判断一次，满足条件就追加到列表末尾，因此不改变原顺序，重复正数不会被消去。最后单独处理空结果，确保不是空白行。

## 再做一次手算

输入1 -2 3 0 -4：先保留1，-2跳过，再保留3，0和-4跳过，结果列表为['1','3']，连接成1 3。输入2 2 -3 1时两个2都要保留。

## 复杂度

设 n 为整数个数、L 为输入字符数，时间 O(L+n)，输入与结果列表及输出占 O(L+n) 空间。

## 易错点与自查

用 >=0 会错误保留0；用 set 会丢失重复值。join 不能直接连接整数列表，会报 TypeError。

比较样例中间值，定位是读取、计算还是输出的错误。不要在最终stdout保留调试文字。
