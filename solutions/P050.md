# P050 小型 CART 分类树训练与预测题解

思路：在当前节点递归用P049规则挑最佳切分。根深度0；达到max_depth、标签纯、无候选、或Gini降低≤1e-12时，成为叶节点。叶节点预测当前训练标签的多数类，票数平局取最小整数标签。否则按≤阈值和>阈值分出两支并递归。查询从根逐层走到叶，不只训练一层。无剪枝、无随机特征。 特征、阈值与查询的大小关系按输入十进制数精确比较；用Fraction从原字符串读取，中点仍保持Fraction，不对x≤阈值的边界加容差。1e-12只用于Gini评分并列/增益判断。

关键步骤：最佳评分与父Gini差≤1e-12就返回多数叶；否则保存(feature,threshold,left,right)，predict按x[feature]≤threshold走左支。 特征、查询、中点都用Fraction，边界判断保持精确。

样例核对：训练x=0..5、标签0 0 1 1 0 0。根最佳阈值1.5与3.5同分，取1.5；左支纯0，右支再以3.5分成纯1和纯0。max_depth=2时查询-1、2.5、5输出0、1、0。

复杂度（对应参考实现）：训练时间 O(dn²(H+1)+dn(H+1)log n)的保守上界，H≤max_depth；预测 O(q(H+1))。额外空间 O(nd(H+1)+dn+q)的保守上界，包含递归暂存样本子集及候选。

易错点：XOR在根处无增益时按本题规则停止，不能声称该贪心树必能拟合所有数据；根深度为0；无增益不要无限递归。 (-0.4+-0.2)/2精确等于-0.3，查询-0.3必须走左支；禁止先转float再构造Fraction。
