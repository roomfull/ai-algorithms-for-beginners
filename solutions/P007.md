# P007 while 计数：题解

先尝试 [题目](../chapters/01_python/problems/P007/README.md)，再对照本页。

## 思路和关键步骤

current 始终是尚未统计的最小正偶数。循环每次恰好计入它，再移动两个整数位置；没有漏掉或重复统计偶数。

## 再做一次手算

n=7：current 依次是2、4、6，count 依次变1、2、3；current 更新成8后条件8≤7为假，退出并输出3。n=1 时第一轮条件就为假，输出0。

## 复杂度

执行 floor(n/2) 轮，时间 O(n)，额外空间 O(1)。

## 易错点与自查

忘记更新 current 会无限循环；条件写成 <n 会在 n 为偶数时漏掉 n。不要把 0 算进去。

比较样例中间值，定位是读取、计算还是输出的错误。不要在最终stdout保留调试文字。
