# P024 按首次出现稳定去重题解

思路：把每行当作一个整数样本，删除重复行，保留各不同样本第一次出现的位置顺序。

关键步骤：按输入顺序遍历；行元组未见过才加入集合与结果列表。

样例核对：2 1 和 1 2 第二次出现时跳过，保留第1、2、5行，共3行。

复杂度（对应本参考实现）：平均时间 O(nd)，空间 O(nd)；假定集合查找平均 O(1)，元组散列需 O(d)。

易错点：只用 set 输出会丢失题目要求的顺序；一行不同于另一行的排列。
