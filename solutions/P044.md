# P044 完整 Lloyd 迭代题解

思路：从给定中心开始，每轮先按P042规则分配，再按P043规则更新。若所有中心的坐标最大绝对变化≤tol，提前停止；否则至多执行max_iter轮。最终必须再按最终中心分配一次，输出标签配合这些中心；即使达到轮数上限也要重分配。

关键步骤：每轮assign→update→判停，循环后再assign最终中心；不要输出上一轮旧中心对应的标签。

样例核对：点0、2、8、10，初始中心0、10。分配0 0 1 1；更新得1、9。再分配仍相同，更新无变化停止；最终中心1、9，标签0 0 1 1。

复杂度（对应参考实现）：时间 O(Tncd+Tnd+Tcd+ncd)，空间 O(nd+cd+n+c)，T≤max_iter。

易错点：固定初始中心，不随机；空簇保留；轮数上限不保证收敛；最后重新分配保证标签一致。
