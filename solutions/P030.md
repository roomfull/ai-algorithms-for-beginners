# P030 小型确定性 SMOTE题解

思路：实现完整小型 SMOTE 的确定性教学版。少数类是原始样本数较少的类别（本题禁止并列）。按其输入顺序列为 minority。对每个少数类基点，只在其余少数类原样本内求平方欧氏距离；输入十进制坐标按精确数值比较距离，按 (距离, 原始输入下标) 升序取前 k 个邻居。第 r 条新样本以 minority[r % m] 为基点，使用该条输入的邻居名次 q（0起）和 λ 做 x+λ(z-x)。新样本不加入邻居搜索。

关键步骤：用Fraction(原始坐标文本)求精确平方距离，不能先转float；排序后预存前 k 个邻居，第 r 条按 r % m 与 q 选点，转float后插值输出。

样例核对：少数类为1，其点按输入顺序是0、10；k=1时互为唯一邻居。第0条以0为基点，λ=0.5得5；第1条以10为基点，λ=0.25得7.5。多数类1、2、3不参与。

复杂度（对应本参考实现）：设少数类数 m，时间 O(nd + m²d + m² log m + gd)，空间 O(nd + mk + gd + m)；逐基点排序临时距离表，不保留全距离矩阵，按题面最多12位小数的有界有理数算术计。

易错点：多数类距离再近也不可用；排除自身而非排除所有同坐标点；十进制等距必须精确判定，再按原始下标；Fraction必须从文本创建，不能从舍入后的float创建；不采用可能破坏排序传递性的epsilon比较。
